---
name: Circuit House admin access
description: The user-selected access model for the assistant behavior controls.
---

Circuit House `/admin` intentionally has no login. Anyone who visits the route can update the shopping assistant's public behavior settings.

**Why:** The user explicitly chose the no-login option after being told that anyone visiting the page could change the assistant settings.

**How to apply:** Preserve this access model and its visible warning unless the user changes the decision.
